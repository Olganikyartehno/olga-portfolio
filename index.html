Таск-трекер · nordflow-task-tracker

Трекер задач для команды

Веб-приложение для ведения задач в команде. Подходит для любых компаний, которым важно не терять задачи и видеть статусы работы.

Что умеет

  • список задач
  • пользователи и исполнители
  • статусы задач (новая, в работе, выполнена и т.п.)
  • фильтры по статусам, срокам, исполнителям
  • сроки (дедлайны)
  • архив задач — задачи не удаляются навсегда, а переезжают в архив

Мой вклад

  • спроектировала и реализовала интерфейс списка задач
  • настроила видимость задач для разных ролей (исполнитель, постановщик, руководитель)
  • продумала фильтры и переход задач в архив

Современный фронтенд-стек: JavaScript/TypeScript, React, работа с состоянием, адаптивный интерфейс.
